## 1. 背景与问题

- H&E 染色免疫细胞的人工判读费时、重复、依赖个人经验;巨噬细胞样本仅 1,624 张,与最多类(8,453 张)相差约 **5 倍**,类别不均衡是核心数据挑战。
- 产品定位:**辅助判读工具,而非替代病理医生**——模型给出识别结果与依据,不确定时明确交还人工。

## 2. 场景调研(公开资料桌面研究)

| 公开资料洞察 | 对本产品的设计输入 |
|---|---|
| 病理人力缺口持续扩大:美国 HRSA 预测到 2037 年全职病理医生缺口约 4,230 人;2024 年综述(Walsh et al.)记录了全球病理医生数量下降与工作量上升的双重压力 | 需求真实性确认:工具价值锚定"提升单次判读效率与一致性",而非替代诊断 |
| 监管已为 AI 病理放行:2021.09 美国 FDA 以 De Novo 路径授权 Paige Prostate——美国首个 AI 数字病理产品,范式为"辅助定位可疑区域 + 病理医生最终确认" | 产品边界依据:本工具"低置信(<50%)强制建议人工复核"的设计与该范式同构;指标上相应更关注召回率(漏检)而非仅准确率 |
| 可解释性是临床信任的关键,但"差的可解释"反而降低信任:Rosenbacke et al.(2024, PMC)显示 XAI 仅在解释清晰、简洁、临床相关时提升医生信任;Evans et al.(2022)提出数字病理"可解释性悖论" | Grad-CAM 配备颜色标尺与「如何解读热力图」说明,并明确标注"颜色为相对影响而非概率"——避免过度解释带来的误导 |
| 数字病理 / 远程阅片被视为应对人力短缺的最重要手段(Labcorp 2026 调研:59% 病理医生持此观点;PathAI 研究测算数字化可带来显著工时节省) | 场景确认:单图快速判读 + 结果可复核的交互式工具是合理切入点 |

## 3. 目标与非目标

- **目标**:3 类细胞(B 细胞 / T 细胞 / 巨噬细胞)的单张图像快速辅助识别;输出置信度与概率分布;低置信时强制提示人工复核;提供可解释依据(Grad-CAM)。
- **非目标**:临床诊断结论、全自动批量判读(列入后续迭代)、多中心数据泛化验证。

## 4. 用户与场景

病理 / 生物学研究人员,在实验或教学场景中对单张 H&E 图像做快速判读与复核。

## 5. 需求与优先级

| 优先级 | 需求 | 说明 |
|---|---|---|
| P0 | 图像上传与识别 | PNG/JPG 单图上传,5 种模型可选(ResNet50 / DenseNet121 / EfficientNet-B0 / ViT-B/16 / MobileNetV3) |
| P0 | 置信度与概率分布展示 | 预测类别 + 置信度分数 + 三类概率条形图 |
| P0 | 低置信预警 | 置信度 < 50% 时显示"建议人工复核"警告(人机协同边界) |
| P1 | 集成模式 | 默认 MobileNetV3 + EfficientNet-B0 软投票;支持全部 10 个两两集成组合 |
| P1 | Grad-CAM 可解释 | 逐集成组件生成热力图并叠加原图,附颜色标尺 |
| P2 | 批量上传 / 结果导出 | 后续迭代 |

## 6. 系统架构与主链路

五层架构(见 `系统架构图.png`):交互层(Streamlit)→ 推理编排层(预处理 → checkpoint 加载 → 推理 → soft voting → 置信度判断)→ 模型层(5 架构)→ 可解释层(Grad-CAM,并行支路)→ 资产层(权重 / 数据 / 报告)。

主链路(见 `判读主链路泳道图.png`):上传 → 预处理(224×224 + 归一化)→ 模型推理(单模型 / 集成 soft voting)→ 结果渲染 → 置信度判断:≥ 50% 正常展示;**< 50% 触发"建议人工复核"预警**。Grad-CAM 热力图与主链路并行生成,汇入结果页。

## 7. 评测与验收标准

- 统一固定测试集;指标:**逐类召回率与宏平均 F1 为主**(准确率仅作参考,避免被多数类主导)、ROC-AUC / LogLoss 为辅,配合混淆矩阵做错判归因。
- 模型选型规则:集成方案必须在宏 F1 上优于最优单模型,且错误相关性足够低(互补)。
- 交付验收:端到端应用可运行、5 个模型 checkpoint 全部可加载、报告评测图表可从 checkpoint 一键复现。

## 8. 关键决策记录(ADR)

1. **集成 vs 单模型**:10 个集成组合全量评测,MobileNetV3 + EfficientNet-B0 软投票宏 F1 0.488 vs 最优单模型 0.455(相对 +7.3%),错误相关性 0.388(互补性强)→ 采用集成。代价:准确率 62.1% → 61.2% 微降,换取类别均衡表现——辅助判读场景更关注逐类召回而非被多数类撑高的准确率。
2. **主指标 = 逐类召回率 + 宏 F1**:5:1 类别不均衡下,准确率是"虚荣指标";召回率直接暴露少数类漏检,混淆矩阵定位错判方向,作为 badcase 归因与迭代依据。
3. **低置信阈值 = 50%**:产品层面定义"模型不确定"的边界,低于阈值不隐藏结果、但强制附加人工复核建议——把最终决定权留给人。
4. **4 类 → 3 类**:CD4+ 与 CD8+ T 细胞按业务口径合并为 T 细胞,与判读使用场景一致。

## 9. 质量运营与实验设计(上线后规划,未执行)

- **质量运营口径**:本项目无线上用户,故无传统埋点 / AB 测试;AI 产品的质量运营等价物 = 统一评测集(回归测试)+ 混淆矩阵 badcase 归因(问题定位)+ 迭代清单(跟踪闭环)。
- **上线后 AB 测试设计**:双盲阅片对照——同一批 H&E 图像随机分流至"AI 辅助组"与"纯人工组",比较判读耗时、与金标一致率、低置信图像的人工复核触发率;按实验室 / 科室维度灰度放量。
- **埋点设计(若上线)**:低置信预警触发率、人工采纳率、逐模型使用占比——均为产品迭代输入。

## 10. 后续迭代方向

批量推理与结果导出 → 概率校准(阈值可配置)→ 多中心数据验证 → 判读报告一键导出。
